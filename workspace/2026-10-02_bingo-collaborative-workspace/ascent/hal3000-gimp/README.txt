GIMP 3.2.8 FOR HAL3000 (OFFLINE)
Prepared 22 November 2026.

WHAT IT IS
- The official GIMP 3.2.8 Windows installer from download.gimp.org. Its SHA-256 matches gimp.org's published checksum
  and its digital signature is valid (GIMP's Windows packager).

INSTALL
1. Run GIMP-HAL3000\INSTALL-GIMP.bat (double-click).
2. It checks the installer, then installs GIMP for this Windows user only (no administrator rights), silently.
3. "GIMP installed: ..." means it worked. Open GIMP from the Start menu.
If it stops, it names the reason and the installer's log file. You can also run gimp-3.2.8-setup.exe by hand and choose
"Install for me only".
